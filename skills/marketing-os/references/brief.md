# Brief fields

| Field | Meaning |
| --- | --- |
| objective | awareness, traffic, leads, sales, launch, retention, views |
| success_metric | how success will be measured: `<metric> <until when>` |
| audience | who the ad is for |
| problem | what the audience struggles with |
| offer / offers | the offer; several offers as `[{ id, keywords }]` when concepts carry different ones |
| facts | every figure, date and claim the user supplied, nothing else |
| offerKeywords | words that show the offer in the first read |
| brandName | the brand name (used to avoid repeating it) |
| mustSay / mustNotSay | required or forbidden wording |
| productBusiness | true when the business sells physical products (own product photos required to publish) |
| cta destination | where the action goes (booking link, WhatsApp, store address); ask if unknown |
